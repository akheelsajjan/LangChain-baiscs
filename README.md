# LangChain Basics

This repository contains a set of LangChain learning notebooks and a minimal Python starter project for exploring core LangChain concepts.

## Project Overview

The workspace is organized as a LangChain basics sandbox with the following key items:

- `1-langchainIntro.ipynb` - introduction to LangChain and basic usage patterns
- `2-steaming&batch.ipynb` - streaming responses and batch prompt execution
- `3-tool.ipynb` - tool use and integrations in LangChain agents
- `4-message.ipynb` - message formats, chat prompts, and conversation flows
- `5-Structured-output.ipynb` - creating structured output using LangChain output parsers
- `6-middleware.ipynb` - middleware patterns for request processing and custom behavior
- `main.py` - simple entry point example
- `requirements.txt` / `pyproject.toml` - dependencies for running the notebooks and sample code
